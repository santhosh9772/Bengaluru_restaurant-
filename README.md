# Bengaluru_restaurant

Dashboard

📌 Project Overview

This project focuses on analyzing restaurant data from Bengaluru using Microsoft Excel. The goal is to organize restaurant information, clean the dataset, and create interactive dashboards to explore restaurant trends, cuisines, quality, services, and features.

🎯 Project Objectives

Clean and organize raw restaurant data.

Identify and correct data quality issues.

Analyze restaurant cuisines, locations, and features.

Create interactive dashboards for easy data exploration.

Present restaurant information in a clear and visual format.

📂 Dataset Information

Dataset: Bengaluru Restaurant Data

Total Records: 9,291

File Format: Excel (.xlsx)

The dataset includes information such as:

Restaurant name and address

Pincode and location coordinates

Cuisine types

Dietary options

Meal types and dishes

Restaurant features

Contact and descriptive information


📈 Key Learnings

Understanding the data cleaning process.

Working with large datasets in Excel.

Using formulas for data calculations.

Organizing data for analysis.

Designing dashboards for business insights.

Presenting information through data visualization.
